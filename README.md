# SharePoint Online Script Samples

This repository contains over 260 script samples for SharePoint Online to help you automate common tasks, generate reports, and manage your environment more effectively.

## Overview

These scripts are designed to address frequent IT Pro requests and provide solutions for tasks that are not available through the SharePoint user interface. The scripts leverage a variety of technologies, including:

*   **PnP PowerShell**
*   **C#**
*   **Client-Side Object Model (CSOM)**
*   **REST API**
